# leandrohenriquez.com

Portfolio di Leandro Henriquez, industrial designer.

Sito statico: HTML, CSS e JavaScript, senza build. Pubblicato con GitHub Pages dal branch `main`.

- `index.html` — home (indice dei lavori, studio, contatti)
- `lavori/oopar/` — pagina progetto con il modello 3D della lampada
- `assets/` — CSS, JS, font, immagini, modello 3D

Per provarlo in locale: `python3 -m http.server` nella cartella e apri http://localhost:8000.
